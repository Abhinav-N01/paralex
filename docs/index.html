😓 The problem today

EB-5 paralegal work is slow and error-prone

Each petition means reviewing hundreds of pages manually, and one missed discrepancy can sink a filing.

  • 📂

    Hundreds of pages per client

    Bank statements, tax returns, wire transfers, passports — often in multiple languages.

  • 🔍

    Manual fund tracing

    Tracing $800K+ from source to USCIS escrow means cross-referencing dozens of documents by hand.

  • 📝

    Memo drafting from scratch

    Source of Funds memos take hours to write — even with templates — because every fact must be cited.

  • ❌

    Easy to miss a document

    Forgetting one exhibit or one year of tax returns can trigger an RFE from USCIS, delaying the petition by months.

✅ What ParaLex does

Automates the review. Keeps you in control.

ParaLex does the reading, checking, and first-draft writing. You review and file.

Get started

Up and running in under 10 minutes

No cloud account needed. Just Python, Node.js, and an API key.

1

Clone the repo

git clone https://github.com/YOUR_GITHUB/paralex
cd paralex
2

Add your Anthropic API key

Get a key at console.anthropic.com

cp backend/.env.example backend/.env
# Edit backend/.env:
ANTHROPIC_API_KEY=sk-ant-your-key-here
3

Install Tesseract OCR (for scanned docs)

# macOS
brew install tesseract

# Ubuntu / Debian
sudo apt install tesseract-ocr
4

Start the app

./start-dev.sh

Or with Docker: docker compose up --build
